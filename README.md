# ONNA MVP 시뮬레이터

외국인 근로자 금융 정착 대리인 에이전트 — PRD v1.0 기반 인터랙티브 MVP.
iM뱅크 샌드박스가 없는 단계이므로 부록 C 인터페이스 계약 전체를 목(mock)으로 재현했다.

## 실행

```bash
npm install
npm run dev   # http://localhost:5199
```

## 구성

| 탭 | 내용 | PRD |
|---|---|---|
| 근로자 앱 | A0–A6 온보딩, B0–B5 급여일 송금, B7 정기송금, C1 내 기록, 도움, 음성(RM-15) | 6.1–6.3 |
| 가족 페이지 | B6 수령 페이지 — 항상 수취인 언어, 앱 불필요, 30일 만료 | RM-12 |
| 사장님 승인 | 카카오톡 링크 1탭 재직 확인 (급여 비노출) | EM-1 |
| 담당자 큐 | 보류 건 재심사. 승인 시 근로자 앱 자동 B5 진행 (데모 SLA 30초 자동 승인) | RM-9 |

## 개발자 패널 (오른쪽)

- **페르소나**: Budi(id·IDR) / Sita(ne·NPR·즉시 확정=취소창 0) / Minh(vi·VND) — 전환 시 세션 리셋
- **이벤트 트리거**: `salary.credited` 웹훅 → 사전점검 → 제안 생성 → B0 푸시
- **규정 점검 시나리오**: 자동 / 통과 강제 / HOLD_LIMIT_MONTHLY / HOLD_DOC_INCOME / HOLD_BENEFICIARY_NEW
- **온보딩·화면**: 등록증 인식 실패 재현(2회 실패 → 사람 연결 노출), 다크 모드, 화면 바로가기
- **지표 + 이벤트 로그**: 부록 D 추적 이벤트, 온보딩 소요 시간
- **에이전트 트레이스**: orchestrator / remit-agent / compliance-agent / rules-engine / bank-core / record-svc 호출 로그

## 설계 원칙 (PRD 반영)

- 언어: 휴대폰 언어 감지 → 추천 카드, id/ne/vi/en/ko 5종, 국기 미사용, 네팔어 Noto Sans Devanagari 행간 1.6
- 금액 계산은 코드, 문장만 템플릿(LLM 슬롯) — 근거 없는 수치 생성 금지 (AG-4)
- 판정은 규칙 엔진, 에이전트는 사유·행동 설명만 (AG-3)
- 카피 린트: 거절·차단·위반·블록체인·DID·크리덴셜·토큰 미사용, "돈은 아직 나가지 않았어요" 필수 문구
- 제안 카드 3버튼 동일 크기, 모든 금액 원화+본국 통화 이중 표기

## 미구현 (PRD 비목표)

스테이블코인 정산, 대출 실행, 사업장 이동·귀국, C2 서류 OCR(스텁), 고용주 콘솔 풀 기능.
